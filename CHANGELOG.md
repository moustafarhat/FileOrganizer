## [1.0.0] - 2026-09-25

First public release.

- Organize files by type, size or date (year / year-month)
- Rename with predefined styles or custom token patterns (`{date:yyyy-MM-dd}_{seq:003}_{kebab}{ext}`)
- Cross-folder duplicate finder (size pre-filter + SHA-256) with undoable quarantine
- Multi-folder plans, drag-and-drop, presets, watch-folder mode
- Preview-then-apply and undo for every batch
- Windows Explorer right-click integration (per-user, no admin)
- Self-contained builds for Windows x64, Linux x64, macOS Apple Silicon and Intel
